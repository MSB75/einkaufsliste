🔒 Datenschutzinformation

📱 Datenspeicherung

Diese App speichert keine persönlichen Daten. Die Einkaufsliste wird ausschließlich lokal im Arbeitsspeicher deines Geräts gehalten und beim Schließen der App automatisch gelöscht. Es werden keine Daten auf externen Servern gespeichert oder übertragen.

☁️ Hosting

Die App wird über GitHub Pages bereitgestellt. Beim Laden der Seite werden technische Zugriffsdaten (z. B. IP-Adresse, Zeitstempel) von GitHub Inc. verarbeitet. Dies ist für den Betrieb der Seite technisch notwendig. Weitere Informationen: GitHub Datenschutzerklärung.

📶 Offline-Nutzung

Die App kann nach dem ersten Laden vollständig offline genutzt werden. Dazu werden App-Dateien (HTML, Bilder) über einen Service Worker im Cache deines Browsers gespeichert. Diese Daten verbleiben ausschließlich auf deinem Gerät.

🖼️ Bildmaterial & Urheberrecht

Die in dieser App verwendeten Produktabbildungen stammen von EDEKA. Alle Rechte an diesen Bildern liegen beim jeweiligen Rechteinhaber. Die Nutzung erfolgt ausschließlich im Rahmen dieser nicht-kommerziellen Anwendung für den SB-Laden Hephata.

🎤 Spracheingabe

Die optionale Spracheingabe nutzt die Web Speech API deines Browsers. Sprachdaten werden direkt vom Browser verarbeitet und nicht von dieser App gespeichert oder weitergeleitet.
